Telegram Alerts Setup
Step 1: Create Bot
Open Telegram, search @BotFather, send /newbot, follow prompts. Copy the API Token.
Step 2: Get Chat ID
Message @userinfobot or @RawDataBot to get your numeric Chat ID. For groups, add bot to group, send a message, then visit:
https://api.telegram.org/bot/getUpdates
Step 3: Configure Environment
Create .env in project root with:
TELEGRAM_BOT_TOKEN=your_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
Step 4: Restart & Enable
Restart the Flask app. The badge will show "Configured". Click "Telegram Alerts" toggle to enable.
